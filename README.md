# Phishing Detector

A Python-based phishing detection system using machine learning to analyze URLs.

## Objective

Analyze URLs and classify them as legitimate or potentially malicious using a trained Artificial Intelligence model.

## Technologies

- Python
- Scikit-learn
- Pandas
- NumPy
- TLDExtract
- Joblib

## Project Structure

```text
phishing_detector/
├── detector/
├── models/
├── .gitignore
├── main.py
├── requirements.txt
└── README.md
```

## Installation

Clone the repository:

```bash
git clone <REPOSITORY_URL>
cd phishing_detector
```

Create and activate the virtual environment:

```bash
python -m venv .venv
```

Windows (PowerShell):

```powershell
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```
